🟥 No Ponto

No Ponto é um mini jogo simples, rápido e divertido feito com HTML, CSS e JavaScript puro.
O objetivo é clicar no ponto vermelho que aparece aleatoriamente na tela, testando sua velocidade e precisão.

O projeto conta com múltiplos modos de jogo, efeitos sonoros e recordes salvos no navegador.

🎮 Modos de Jogo

🔴 Clássico

Clique no ponto vermelho

A cada clique ele se move para um local aleatório

Ideal para treino e diversão casual

⏱️ Contra o Tempo

30 segundos para marcar o máximo de pontos possível

Cada clique vale +1 ponto

Exibe:

Cronômetro

Pontuação atual

🏆 Maior recorde

Ao bater um recorde:

O número pisca

Um som especial é reproduzido

Ao fim do tempo:

Um alarme sonoro toca

O jogo é encerrado automaticamente

🚀 Como jogar

Abra o arquivo index.html no navegador
(ou utilize o Live Server no VS Code)

Clique em Play

Escolha um modo de jogo:

Clássico

Contra o Tempo

Clique no ponto vermelho o mais rápido que puder 🔴🎯

🧠 Tecnologias utilizadas

HTML5

CSS3

JavaScript (ES6)

Áudio nativo com <audio>

localStorage para salvar recordes

🗂 Estrutura do projeto
no-ponto/
├── index.html          → Tela inicial (logo + botão Play)

├── selecao.html        → Tela de seleção de modos

├── jogo.html           → Modo Clássico

├── jogo-tempo.html     → Modo Contra o Tempo

├── style.css           → Estilos das telas

├── imagens/            → Logo e botão Play

└── sons/

    ├── click.mp3       → Som de clique
    
    ├── recorde.mp3     → Som ao bater recorde
    
    └── alarme.mp3      → Som de fim de tempo
